# Gas Station & Kiosk System

Ein interaktives Kassensystem für Tankstellen, geschrieben in Python.

### Features:
- **Kraftstoff-Rechner:** Auswahl zwischen verschiedenen Benzin- und Dieselarten mit automatischer Preisberechnung pro Liter.
- **Warenkorb-Funktion:** Benutzer können mehrere Artikel aus dem Kiosk (Burger, Getränke, Schokolade) hinzufügen, bis sie fertig sind.
- **Dynamische Quittung:** Erstellung einer detaillierten Endabrechnung.

Dieses Projekt zeigt die Anwendung von **Dictionaries, While-Loops und User-Input-Processing**.
